Fitur Unggulan

🔐

100% Lokal

API key tersimpan di perangkat Anda. Tanpa akun, tanpa login, tanpa perantara. Privasi terjamin sepenuhnya.

🔄

Multi-Provider

Support Claude, Gemini, GPT, dan endpoint OpenAI-compatible seperti Groq. Pilih sesuai kebutuhan Anda.

⚡

Cepat & Ringan

Dibangun dengan Tauri + Rust. Desktop app yang responsif tanpa overhead berat seperti Electron.

🛡️

Backup Terenkripsi

Fitur backup API key opsional ke VPS dengan enkripsi AES-256-GCM. Kontrol penuh di tangan Anda.

🖥️

Cross-Platform

Jalan di Windows, Linux, dan macOS. Installer siap pakai atau build sendiri dari source.

📖

Open Source

MIT License. Kode terbuka, transparan, dan dapat diaudit. Kontribusi dan feedback welcome.

Mulai Menggunakan

1. Download & Install

Unduh installer sesuai OS Anda dari halaman download atau GitHub Releases. Proses instalasi standard seperti aplikasi biasa.

2. Pilih Provider

Buka app dan pilih provider AI yang ingin digunakan. Built-in support untuk Claude, Gemini, OpenAI, atau custom endpoint OpenAI-compatible.

3. Masukkan API Key

Masukkan API key dari provider pilihan Anda. Key disimpan lokal di komputer Anda, tidak pernah dikirim ke server chanthecno.

Dapatkan key di: console.anthropic.com, platform.openai.com, dll

4. Mulai Chat

Ketik pertanyaan atau instruksi kepada AI. Response dikirim langsung dari app Anda ke provider, lalu kembali ke layar Anda.

Custom Endpoint

Untuk provider lain, gunakan mode custom endpoint. Contoh: Groq, self-hosted models, atau endpoint private.

https://api.groq.com/openai/v1/chat/completions

Backup (Opsional)

Fitur backup terenkripsi tersedia untuk menyimpan API key di VPS. Aktifkan hanya jika Anda percaya dan menjalankan VPS sendiri.
